**Jianke Assistant** (elnbian) is a fork for Jianke intranet ELN / LIMIS. Install from **this repo's Releases**, not the upstream Cebian store build.

## Recommended: GitHub Release

[Jianke Assistant Releases](https://github.com/shjk0817/elnbian/releases)

1. Download **`elnbian-x.x.x-chrome.zip`**
2. Extract to a fixed folder
3. Open `chrome://extensions` (or Edge extensions)
4. Enable Developer mode
5. Load unpacked → select the extracted folder
6. To update: replace files and click Reload on the extensions page

> Tool catalog: [docs/TOOLS.md](https://github.com/shjk0817/elnbian/blob/master/docs/TOOLS.md)

## Upstream Cebian stores (not this fork)

These install **upstream Cebian** without ELN / LIMIS tools:

- [Chrome Web Store](https://chromewebstore.google.com/detail/dnfmklmdbipiahdjiogaoemjaiodomdf)
- [Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/kakfgcmbiacmclkjboijakkhlhioopcd)
- [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/cebian-ai-side-panel-agent/)

## After install

Configure **Settings → AI Providers**, then **ELN / LIMIS** connection pages to sync intranet login state.
