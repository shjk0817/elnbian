**建科助手**（elnbian）面向建科內網 ELN / LIMIS，**請從本倉庫 Release 安裝**，而非上游 Cebian 商店版。

## 推薦：GitHub Release

[建科助手 Releases](https://github.com/shjk0817/elnbian/releases)

1. 下載最新 **`elnbian-x.x.x-chrome.zip`**
2. 解壓到固定目錄
3. 開啟 `chrome://extensions` 或 Edge 擴充功能頁
4. 開啟「開發人員模式」
5. 「載入未封裝項目」→ 選擇解壓目錄
6. 更新：覆蓋解壓目錄後在擴充功能頁點「重新載入」

## 上游 Cebian 外掛商店（非本 fork）

以下為**上游 Cebian**，不含 ELN / LIMIS 內建工具：

- [Chrome 外掛程式（Cebian）](https://chromewebstore.google.com/detail/dnfmklmdbipiahdjiogaoemjaiodomdf)
- [Edge 外掛程式（Cebian）](https://microsoftedge.microsoft.com/addons/detail/kakfgcmbiacmclkjboijakkhlhioopcd)

## 安裝後

在 **設定 → AI 提供商** 與 **ELN / LIMIS 連線** 同步內網登入態後即可使用。
