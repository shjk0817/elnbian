## 1. 概述

**模板编辑**是 ELN 平台的核心功能，用于设计检测参数的电子原始记录表单。一个「参数模板」包含三块配置：

| 配置块 | 存储字段 | 用途 |
|--------|---------|------|
| 表单 Schema | `formTemplateJson` | Formily 驱动的检测数据录入界面 |
| 数据配置 | `extra` | 计算公式、输出值、检测日期策略 |
| 打印表格 | `tableTemplateJson` | x-spreadsheet 驱动的报告/原始记录表格 |

**技术栈：**

- 前端：React + UMI + Formily Designable + Ant Design
- 公式编辑器：Monaco Editor（22 个内置函数）
- 表格编辑器：x-spreadsheet（Canvas 渲染）
- 认证：JWT 存于 `localStorage['taurus_auth_token']`

**核心设计原则：** 编辑页所有操作（拖组件、改属性、配公式、画表格）**只改浏览器内存**，点击顶部「**保存**」后一次性提交到服务器。

## 2. 进入编辑页

### 2.1 路由

| 页面 | URL |
|------|-----|
| 登录 | `/design/user/login` |
| 参数模板列表 | `/design/table/template-list` |
| **模板编辑** | `/design/table/template-design?id={templateId}&backPath=/table/template-list` |

### 2.2 从列表进入

1. 左侧选择 **分类 → 样品**
2. 右侧模板列表点击「**继续搭建**」或「查看」
3. 进入编辑页，URL 携带 `id={templateId}`

### 2.3 新建模板

列表页点击「新建模板」，填写：

| 字段 | 必填 | 说明 |
|------|------|------|
| 样品名称 | 是 | 当前选中样品（预填） |
| 分类 | 是 | 当前选中分类（预填） |
| 参数名称 | 是 | 如「硫酸盐三氧化硫、烧失量分析」 |
| 受控编号 | 否 | 全局唯一，启用前必须设置 |
| 标准 | 否 | 如 GB/T 176-2017 |
| 输出值 | 否 | 展示用文本 |

新建后自动创建 **version=1 草稿**，可直接进入编辑。

| UI 名称 | x-component | 说明 |

| 弹性间距 | Space | 横向间距 |
| 表格 | Table / TableRow / TableCell | **表单内矩阵**（非 x-spreadsheet） |

#### 自增组件（3）

| UI 名称 | x-component | 说明 |
|---------|-------------|------|
| 自增卡片 | ArrayCards | 动态增减卡片 |
| 自增表格 | ArrayTable | 动态行表格 |
| 固定行数表格 | ArrayFixTable | 平行测定等固定行场景 |

#### 展示组件（2）

| UI 名称 | x-component | 说明 |
|---------|-------------|------|
| 格式化文本 | FormattedText | 格式化展示 |
| 文本 | Text | 公式说明、静态文字 |

### 4.2 典型嵌套结构

```
Card（环境与方法）
└── FormGrid (columns=2)
    ├── Input（检测地点）
    └── DatePicker（检测日期）

Card（SO3检测）
├── Text（公式说明：SO3(%) = ...）
├── Table（检测数据矩阵）
│   └── TableRow → TableCell → NumberPicker（G1平行1）
└── NumberPicker（SO3平均值，x-pattern=disabled）
```

**要点：**

- 容器组件 `type: "void"`，标题在 `x-component-props.title`
- 表单字段 `type: string/number/boolean/array`，标题在 `title`
- **计算结果字段**用 `x-pattern: "disabled"`（不是 readOnly）
- 每个节点需 `name`（唯一标识）、`x-designable-id`、`x-index`

### 4.3 右侧属性面板

#### 字段属性（通用）

| UI 名称 | Schema 字段 |
|---------|--------------|
| 字段标识 | `name` |
| 标题 | `title` |
| 描述 | `x-decorator-props` |
| 展示状态 | `x-pattern`：editable / disabled / readOnly |
| 是否显示 | `x-display`：visible / hidden / none |
| 默认值 | `default` |
| 必填 | `required: true` |
| 可选项 | `enum` 或 `x-component-props.options` |
| 响应器规则 | `x-reactions` |
| 校验规则 | `x-validator[]` |

#### 组件特有属性示例

**NumberPicker：**

```json
"x-component-props": {
  "precision": 4,
  "step": 0.0001,
  "min": 0,
  "max": 100
}
```

**Select / Radio / Checkbox：**

```json
"enum": [
  { "label": "正常", "value": "normal" },
  { "label": "异常", "value": "abnormal" }
]
```

**Text（公式说明）：**

```json
"x-component": "Text",
"x-component-props": {
  "content": "SO3(%) = (G1-G2)/G × 0.343 × 100",
  "mode": "normal"
}
```

#### 表单级属性（选中根节点）

| 属性 | 默认值 | 说明 |
|------|--------|------|
| labelCol | 6~12 | 标签栅格宽度 |
| wrapperCol | 12 | 组件栅格宽度 |
| labelWrap | true | 标签换行 |

## 5. Tab 2：数据配置

数据存在 `extra` 字段，与表单一起保存。含三个子 Tab。

### 5.1 数据计算（expressionItems）

**对话框字段：**

| 字段 | 必填 | 说明 |
|------|------|------|
| 名称 | 是 | 如「SO3计算-平行1」 |
| 依赖字段 | 否 | 变量名 + 来源字段路径 |
| 允许空值计算 | 否 | Switch |
| 表达式 | 是 | ELN 函数语法 |
| 写入表单值 | 否 | 结果写入的目标字段 |

**存储结构：**

```json
{
  "id": 1787235342582,
  "name": "expr_1787235342582",
  "title": "SO3计算-平行1",
  "expression": "ROUNDING(IFERROR((A - B) / C * 0.343 * 100, 0), 2)",
  "writeFormValue": "SO3_result_1",
  "variables": [
    { "name": "A", "value": "G1_1", "type": "number" }
  ]
}
```

**变量路径规则：** `value` 填字段 `name`（如 `G1_1`），UI 显示为「卡片-字段」路径。

### 5.2 输出值配置（outputItems）

用于向 LIMS 回传检测结果。

```json
{
  "id": 1784007024073,
  "name": "raw##SO3检测-SO3平均值(%)##SO3_avg"
}
```

**name 格式：** `raw##{卡片标题}-{字段标题}##{字段name}`

### 5.3 检测日期配置（detectionDateConfig）

```json
{
  "missingPolicy": "warnOnly",
  "outputFormat": "YYYY-MM-DD",
  "items": [
    {
      "id": 1784007024073,
      "title": "质控样与备注-分析日期",
      "path": "analysisDate",
      "component": "DatePicker",
      "valueKind": "single"
    }
  ]
}
```

**missingPolicy 取值：**

| 值 | 含义 |
|----|------|
| block | 缺失时阻止提交审核 |
| warnOnly | 缺失时仅提示（默认） |
| ignore | 缺失时忽略 |

**valueKind 取值：**

| 值 | 适用组件 |
|----|---------|
| single | DatePicker |
| range | DatePicker.RangePicker |
| start | 范围的开始日期 |
| end | 范围的结束日期 |

## 6. Tab 3：表格搭建

基于 **x-spreadsheet**，用于设计打印/报告用 Excel 式表格，与 Tab1 中 Formily `Table` 组件无关。

### 6.1 工具栏（23 项）

撤销/恢复、格式刷、清除格式、数据格式(11种)、字体(7种)、字号(16档)、加粗/斜体/下划线/删除线、字体色/填充色、边框(10种)、合并单元格、对齐、自动换行、**绑定数据**、**绑定表格数据**。

### 6.2 数据绑定（特有功能）

| 功能 | 说明 |
|------|------|
| **绑定数据** | 单元格 ← 表单字段值（单值） |
| **绑定表格数据** | 单元格区域 ← ArrayTable 等循环数据 |

绑定信息存在 `tableTemplateJson` 中，随保存 PATCH 一并提交。

### 6.3 存储结构（概要）

```json
{
  "rows": {
    "0": { "cells": { "0": { "text": "样品编号", "style": 1 } } }
  },
  "cols": { "0": { "width": 120 } },
  "styles": [{ "font": { "bold": true } }],
  "merges": ["0_0:0_2"],
  "bindings": {
    "0_1": { "type": "field", "fieldPath": "sampleNo" }
  }
}
```

> 具体 bindings 字段名以保存后 GET 回读为准，不同版本可能略有差异。

## 8. 保存与版本

### 8.1 保存流程

```
点击「保存」
  → PATCH /api/v1/form-template-version/{versionId}
  → GET  /api/v1/form-template/{templateId}   # 刷新详情
```

**PATCH 请求体（三块始终一起提交）：**

```json
{
  "formTemplateJson": { "form": {...}, "schema": {...} },
  "tableTemplateJson": { ... },
  "extra": {
    "expressionItems": [],
    "outputItems": [],
    "detectionDateConfig": null
  }
}
```

### 8.2 版本状态

| status | 含义 |
|--------|------|
| 1 | 草稿 |
| 2 | 已启用 |

### 8.3 模板生命周期

```
新建 → 草稿编辑 → 设置受控编号 → 启用
                    ↓
              已启用模板 → 发起变更 → 新草稿 → 编辑 → 设新编号 → 重新启用
```

| 操作 | API | 说明 |
|------|-----|------|
| 设置受控编号 | `PATCH .../form-template-version/{id}` `{ controlledNo }` | 全局唯一 |
| 启用 | `POST .../form-template-version/{id}/activate` | 需先设受控编号 |
| 发起变更 | `POST .../form-template/{id}/change` | 已启用模板创建新草稿 |

**受控编号格式示例：** `JC/DJL 01-040-2026`、`TEST/MCP-E2E-1787712179061`

### 9.1 formTemplateJson

```json
{
  "form": {
    "labelCol": 6,
```

| `x-validator` | 校验规则数组 |

## 10. 表达式引擎

### 10.1 内置函数（22 个）

| 分类 | 函数 |
|------|------|
| 数学 | ROUNDING, ABS, SQRT, POWER, LOG, LN, EXP, MOD, INT, CEILING, FLOOR |
| 统计 | AVERAGE, SUM, MAX, MIN, COUNT, STDEV, VAR, MEDIAN |
| 逻辑 | IF, IFERROR |
| 时间 | NOW |

### 10.2 编写规范

- 变量用大写字母（A, B, C...），在「依赖字段」中映射到表单字段
- 嵌套：`ROUNDING(IFERROR((A - B) / C * 0.343 * 100, 0), 2)`
- 结果写入表单字段后，该字段应设 `x-pattern: "disabled"`

### 10.3 示例

**烧失量（平行1）：**

```
ROUNDING(IFERROR((A - B) / C * 100, 0), 2)
```

变量：A=G1_1, B=G2_1, C=sampleWeight

**平均值：**

```
ROUNDING(AVERAGE(A, B), 2)
```

## 12. MCP Agent 操作指南

本项目提供 **eln-mcp** MCP Server（66 工具），供 AI Agent 程序化操作模板编辑。

### 12.1 配置

```json
{
  "mcpServers": {
    "eln-form-design": {
      "command": "node",
      "args": ["/Users/slouch/Desktop/eln-mcp/dist/index.js"],
      "env": {
        "ELN_BASE_URL": "http://10.1.228.52:13002/api/v1",
        "ELN_ALLOWED_CATEGORY_IDS": "50"
      }
    }
  }
}
```

### 12.2 安全约束

| 允许 | 禁止 |
|------|------|
| 测试分类（50）下创建/编辑/保存 | 修改非测试分类已有数据 |
| 设置受控编号 | 启用模板（activate） |
| 预览会话 | 发起变更、检测记录提交 |

### 12.3 标准工作流

```
1. login
2. create_template(categoryId=50, sampleName="验证样品", name="参数名")
3. [Tab1] add_component → set_property → set_enum_options
4. [Tab2] add_formula → add_output_item → set_detection_date
5. [Tab3] set_spreadsheet_cell → bind_cell_data
6. save_template
7. set_controlled_no("TEST/MCP-{timestamp}")   # 可选
8. create_preview_session                       # 可选
```

### 12.4 UI 功能 → MCP 工具映射

完整映射表见：[`docs/reverse-engineering/06-editor-feature-matrix.md`](../reverse-engineering/06-editor-feature-matrix.md)

| Tab | 代表工具 |
|-----|---------|
| 表单 | `add_component`, `set_property`, `set_validator`, `init_array_table` |
| 数据 | `add_formula`, `add_output_item`, `add_detection_date_item` |
| 表格 | `set_spreadsheet_cell`, `bind_cell_data`, `bind_cell_loop` |
| 通用 | `save_template`, `set_controlled_no`, `validate_template` |

### 12.5 内存编辑模型

MCP Server 在内存中维护编辑会话（templateId、versionId、Schema、extra、table），细粒度工具只改内存，**必须调用 `save_template` 才会 PATCH 到服务器**。

```
Agent 调用 add_component / add_formula / set_spreadsheet_cell
  → 仅改 MCP 内存 session
Agent 调用 save_template
  → PATCH form-template-version/{versionId}
```

## 13. 常见模式与示例

### 13.1 多 Card 检测表单（水泥分析）

```
envCard      → 环境与方法（Input, TextArea）
instrCard    → 仪器与状况（Checkbox.Group, Radio.Group）
so3Card      → SO3 检测（Table 矩阵 + 公式 + 结果字段 disabled）
lossCard     → 烧失量检测（同上）
qcCard       → 质控样与备注（DatePicker, TextArea）
```

### 13.2 平行测定（固定 2 行）

使用 `ArrayFixTable`，rowCount=2：

```
init_array_fix_table(
  name="so3Table", title="SO3检测数据", rowCount=2,
  columns=[{ columnName:"g1", fieldName:"G1", fieldType:"Number" }, ...]
)
```

### 13.3 公式链

```
SO3结果1 = f(G1_1, G2_1, G)     → writeFormValue: SO3_result_1
SO3结果2 = f(G1_2, G2_2, G)     → writeFormValue: SO3_result_2
SO3平均值  = AVERAGE(结果1, 结果2) → writeFormValue: SO3_avg
```

三个结果字段均设 `pattern: disabled`。

### 13.4 输出值绑定

每个 disabled 结果字段对应一条 outputItem：

```
add_output_item(cardTitle="SO3检测", fieldTitle="SO3平均值(%)", fieldName="SO3_avg")
→ raw##SO3检测-SO3平均值(%)##SO3_avg
```

## 14. 注意事项与边界

### 14.1 编辑页 vs 检测记录

| 功能 | 所在系统 | 说明 |
|------|---------|------|
| 模板设计 | ELN (10.1.228.52) | 本文档范围 |
| 检测数据填写/提交 | 移动端 + LIMS (10.1.228.22) | 不在模板编辑 MCP 范围 |
| LIMS 参数绑定 | LIMS 系统 | 独立流程 |
| 电子原始记录审批 | LIMS 系统 | 独立流程 |

### 14.2 常见错误

| 问题 | 原因 | 解决 |
|------|------|------|
| 检测日期列表「暂无数据」 | API 存了错误格式 `{ valueType, fieldPath }` | 使用正确的 `detectionDateConfig.items[]` 结构 |
| 启用失败 400 | 未设受控编号 | 先 PATCH controlledNo |
| 公式不生效 | 未 save_template | 公式在 extra 中，需保存 |
| 计算字段可编辑 | 未设 disabled | `x-pattern: "disabled"` |
| 受控编号冲突 | 全局唯一 | 测试环境用 `TEST/` 前缀 |

### 14.3 不存在的 API

以下端点经探测返回 404，**不要依赖**：

- `GET /form-template-version/{versionId}`（单独获取版本）
- `DELETE /form-template-version/{versionId}`
- `PUT /form-template/{id}`
- cancel-change / abandon / discard
